# P6-2 계획: App 분리 + dynamic import 준비

작성일: 2026-08-20
상태: 준비 단계 (기능 동결 유지)

## 목표
- app-main.js에 남아 있는 App 본체를 논리적으로 분리할 수 있는 구조 만들기
- 아직 라이브 동작은 변경하지 않음

## 안전한 진행 순서
1. src/ 구조 설명 및 계획 문서화 ← 현재 단계
2. src/core/app-main.js를 분석해서 큰 블록 주석으로 구역 나누기 (동작 동일)
3. 뷰별(chat / memo / places / admin / calendar) 경계 표시
4. 이후 실제 파일 분리 (별도 작은 커밋으로)

## 주의사항
- index.html과 assets/ 폴더는 절대 건드리지 않음
- 라이브 스모크가 통과해야만 다음 단계로 진행
- 한 번에 큰 수정을 하지 않음

## 진행 기록
- 1단계 완료: src 구조 설명 + 계획 문서
- 2단계 진행중: app-main 구역 지도 문서화 (코드 미변경)

- 3단계 완료: 뷰 분기(chat/memo/places/gallery/settlement/admin) 주석 표시
- 다음: 실제 파일 분리는 별도 브랜치에서 아주 작은 단위로만 진행
