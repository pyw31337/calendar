# 렛츠 캘린더 경쟁 분석 및 제품 고도화 계획

작성일: 2026-10-23

## 결론

렛츠 캘린더는 공유 캘린더, 채팅, 사진·추억, 장소, 메모, 정산, AI 미디어 분석을 한 서비스에 묶은 점이 가장 큰 차별점이다. 반면 경쟁 서비스는 각자의 핵심 업무를 더 짧은 흐름으로 완성한다. 따라서 기능을 무작정 늘리기보다 **입력 자동화**, **실시간 협업**, **사진 회고 품질**, **정산 신뢰도**를 제품의 네 가지 핵심 축으로 삼는다.

## 현재 제품의 강점

- 일정에 연결된 사진·채팅·장소·메모·정산을 한 캘린더에서 추적할 수 있다.
- 사진 인덱스 페이지네이션, 썸네일 변형, 낙관적 업로드 반영, AI 태그 근거/검토 흐름이 이미 존재한다.
- 개인 이름·장소 별칭과 기존 태그를 비교해 중복 태그를 줄이는 방어 로직이 있다.
- PWA, 모바일 하단 메뉴, 백드롭, 공유 페이지, 운영 감사 도구까지 포함해 단일 기능 앱보다 범위가 넓다.

## 우선순위 로드맵

### P0 — 입력에서 저장까지의 신뢰성 (이번 분기)

1. **AI 스마트 수집함**: 사진/PDF/텍스트/링크를 넣으면 일정·장소·담당자·마감·금액 후보를 만든다.
2. 모든 후보는 원문, 추출 근거, 신뢰도, 충돌 필드를 보여주고 사용자가 한 번에 승인/수정한다.
3. 이미 존재하는 태그·일정·정산 항목은 후보 생성 단계에서 제외하고, 같은 항목은 “기존 항목과 연결”로 제안한다.
4. 업로드·분석·저장 상태를 `대기 → 처리 중 → 검토 필요 → 적용/실패`로 표시하며 실패 작업은 재시도 가능하게 한다.

### P1 — 협업과 회고의 체감 품질 (30~60일)

1. 사진 인덱스 revision 기반 교차 세션 실시간 갱신(이번 변경으로 30초 경량 감시와 포그라운드 재동기화를 추가).
2. FamilyAlbum식 월간 하이라이트와 “오늘 몇 년 전” 회고를 일정·사람·장소 필터와 함께 제공한다.
3. 일정별 활동 피드에 누가 읽었는지, 누가 승인했는지, 마지막 동기화 시점을 표시한다.
4. 외부 캘린더 ICS/Google/Outlook 가져오기와 중복 이벤트 병합을 온보딩 단계에서 제공한다.

### P2 — 정산과 가족 운영 확장 (60~90일)

1. Splitwise식 부채 단순화와 상환 경로 미리보기를 정산 카드에 추가한다.
2. Cozi식 담당자·반복 집안일·장보기 목록을 일정에서 파생시키고 완료 이력을 남긴다.
3. FamilyWall식 위치 공유는 선택형·시간 제한형·멤버별 권한으로만 제공한다.
4. 월간 데이터 내보내기(JSON/CSV/ZIP)와 사진 원본 백업 검증을 제공한다.

## 품질 지표

- 사진 업로드 후 다른 세션에 표시되기까지 P50 5초 이하, P95 30초 이하
- AI 후보 중 기존 태그 중복 제안률 1% 미만
- AI 후보 승인 전 자동 쓰기 0건
- 사진 분석 실패 작업의 재시도 성공률 95% 이상
- 정산 중복 항목 생성 0건, 계산 불일치 0건
- 보관함 첫 인터랙션 가능 시간 P95 2초 이하
- 모바일 PWA에서 화면 잘림/하단 메뉴 가림 회귀 0건

## 이번 구현

`useGalleryPhotoIndex`에 서버의 작은 summary revision을 30초마다 확인하는 경량 감시를 추가했다. revision이 바뀐 경우에만 첫 페이지를 다시 읽으므로 전체 사진을 반복 다운로드하지 않는다. 포그라운드 복귀, 네트워크 재연결, 창 focus에서도 같은 검사를 수행하며, 업로더 본인은 기존 낙관적 UI로 즉시 반영된다.

이 구조는 FamilyAlbum/FamilyWall의 “다른 구성원에게 즉시 보인다”는 사용성을 가져오면서도, 보관함 진입 시 전체 사진을 한꺼번에 읽어 브라우저가 멈추던 문제를 다시 만들지 않는다.
