# 모바일 체크리스트 (P5)

대상: 사용자 90%+ 모바일 (iPhone / Android, Safari / Chrome / Edge / Firefox / Whale)

## 핵심 화면
- [ ] 메인 캘린더 로드, 일정 탭 → 일정 레이어팝업
- [ ] 사이드메뉴: 다크모드 / 글자크기 / 채팅알림 (캘린더별)
- [ ] 채팅: 전송, 이미지, 스크롤 위로 이전 메시지
- [ ] 갤러리 페이지: 썸네일 → 라이트박스, 사진/링크 탭
- [ ] 장소: 리스트 선택, 지도 마커, 드래그 유지
- [ ] 메모: 작성/댓글, 스페이스바 입력
- [ ] 정산: 탭 전환, 추가/삭제 (confirm 1회)
- [ ] 공유하기: /share/... URL + 복사 + QR

## 입력/키보드
- [ ] input font-size ≥ 16px (iOS 줌 방지)
- [ ] 가상 키보드에 입력창 가리지 않음
- [ ] 백드롭은 브라우저 하단에서 상승

## 제스처
- [ ] 라이트박스 스와이프/닫기
- [ ] 지도 핀치 줌, 마커 선택 후 지도 드래그 가능
- [ ] 사이드메뉴 스크롤 (메뉴 길 때)

## 배포 후
    npm run check:share-urls
    npm run smoke:live
