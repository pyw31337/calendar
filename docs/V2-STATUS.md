## 2026-09-14 운영 원본 감사 (읽기 전용)

- `/tmp/cw-full-audit`로 `cw`를 포함한 3개 캘린더의 현재 Firestore 원본과 하위 컬렉션을 내보냈다. 내보내기는 읽기 전용이며 원본을 변경하지 않는다.
- `cw`의 `confirmedMeetings` 54행 중 `confirmed:false`는 40행이다. `2026-08-08`은 `confirmed:false`, 사진 27장, 메모/활동 로그에 `13시 광명시영유아과학체험센터`와 저녁 식사 기록이 있지만 `meeting_confirm` 로그는 없다. 즉 “실제로 모였는가”와 “확정 버튼을 눌렀는가”를 자동으로 동일시할 수 없는 후보 행이며, 사용자 승인 없는 일괄 복구는 보류한다.
- 확정 상태 변경 로그는 `2026-08-06`, `08-16`, `08-22`, `08-23`, `08-25`, `08-27`, `09-12`, `10-03`, `10-04`, `10-07`, `10-09`에서만 확인됐다. V2 CSS 배포 이전에 생성된 원본 상태이므로 화면 스타일이 해당 값을 바꾼 근거는 없다.
- `ops:gallery-contract-audit` 결과 `cw`는 676개 인덱스 행과 원본 사진 계약이 일치하며, stale tag 1건과 orphan comment thread 4건만 별도 후속 조사 대상으로 남아 있다. `jhair`와 `kkot`은 계약 경고가 없다.
- 현재 홈 갤러리는 `photoIndex`의 `timestamp DESC` 순으로 처음 6장을 노출한다. 이는 사용자 큐레이션 순서가 아니며, 목업의 정렬 규칙과 맞추는 별도 디자인/제품 결정이 필요하다.
